# PILLAR Connect — Cornerstone AFC

This repository is an **interface-only starter** for PILLAR Connect. It does **not** implement authentication, role permissions, policy question banks, exam scoring, remediation, records, or any protected employee data.

## Run locally

1. Install Node.js 20.9 or later.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Vercel

Upload the **contents** of this folder to the GitHub repository root, including `package.json` and the `app` directory. Vercel should detect Next.js. Confirm Deployment Protection before distributing a preview URL.

Do not enter employee or resident information into this demo. Production use requires authentication, authorization, privacy/security review, policy source verification, data storage, and testing.
